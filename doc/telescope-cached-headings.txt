1. INTRO                                   *telescope-cached-headings-intro*

telescope-cached-headings.nvim is a Telescope extension for fast heading
navigation in massive files (100k+ lines). Instead of parsing headings on
every invocation, the plugin writes a small cache file on first use. On
subsequent openings only the cache is read, making the picker essentially
instant.

Supported filetypes out of the box:

  • LaTeX   (`tex`)       – \part, \chapter, \section, \subsection,
                            \subsubsection  (and optionally starred variants)
  • Markdown (`markdown`) – # through ######
  • Org-mode (`org`)      – * through ******

==============================================================================
2. REQUIREMENTS                        *telescope-cached-headings-requirements*

  • nvim-telescope/telescope.nvim
  • nvim-lua/plenary.nvim

==============================================================================
3. SETUP                                    *telescope-cached-headings-setup*

Load and configure the extension inside your Neovim config: >

  require("telescope").setup({
    extensions = {
      cached_headings = {
        -- all keys are optional; defaults are shown
        cache_strategy    = "global",
        allowed_filetypes = { "tex", "markdown", "org" },
        auto_update       = false,
        enable_smart_jump = true,
        smart_jump_window = 200,
        include_starred   = false,

        -- Multi-file LaTeX: follow \input / \include / \subfile directives
        scan_includes          = false,
        recursive_limit        = 5,
        ignore_include_pattern = "",

        -- Subfile toggle
        root_file          = "",
        subfile_toggle_key = "<C-g>",

        -- Copy heading title to clipboard
        copy_label_key = "<C-y>",
        copy_transform = nil,  -- table, function, or nil; see |cached-headings-copy|
      },
    },
  })

  require("telescope").load_extension("cached_headings")
<

Suggested keybinding: >

  vim.keymap.set("n", "<leader>fh",
    "<cmd>Telescope cached_headings<cr>",
    { desc = "Find headings (cached)" })
<

==============================================================================
4. USAGE                                    *telescope-cached-headings-usage*

Open the picker: >

  :Telescope cached_headings
<

  • The first time you open the picker for a file the cache is generated
    automatically. Subsequent opens read the cache directly.

  • Headings are displayed with level-based indentation so the document
    hierarchy is immediately visible.

  • Selecting a heading performs a smart jump
    (see |telescope-cached-headings-smart-jump|).

To force-rebuild the cache after making structural changes: >

  :CachedHeadingsUpdate
<

To delete every cache file and start fresh: >

  :CachedHeadingsWipeAll
<

==============================================================================
5. SMART JUMP                        *telescope-cached-headings-smart-jump*

When you select a heading the plugin checks whether the cached line number
still holds the expected text in the live buffer.

  Match    The heading is exactly where the cache says it is. Jump silently.

  Shifted  The heading is not at the cached line, but is found within
           ±`smart_jump_window` lines. Jump to the new position and update
           the cache entry automatically.
           Message: "Heading shifted. Run :CachedHeadingsUpdate."

  Missing  The heading cannot be found anywhere in the search window. Jump
           to the original cached line and warn the user.
           Message: "Heading not found. Run :CachedHeadingsUpdate."

Set `enable_smart_jump = false` to skip verification and jump directly to the
cached line number without any checks.

6. MULTI-FILE LATEX                   *telescope-cached-headings-multifile*

When `scan_includes = true` the picker follows `\input`, `\include`, and
`\subfile` directives and shows all headings from the entire document tree
in document order. Each heading from an included file is annotated with its
relative filename (shown in a dimmed colour), so you can filter by filename
as well as heading text.

Example configuration: >

  cached_headings = {
    scan_includes          = true,
    recursive_limit        = 5,          -- max nesting depth
    ignore_include_pattern = "appendix", -- skip paths matching this pattern
  }
<

Jumping to a heading in an included file opens that file automatically.

==============================================================================
7. SUBFILE TOGGLE                      *telescope-cached-headings-subfile*

When editing a LaTeX subfile (using the `subfiles` package), the plugin
detects the root file by looking for a `\documentclass[root.tex]{subfiles}`
declaration near the top of the current file.

When detected, the picker title reflects the current mode and the toggle key:

  Local mode (default) ~
    Shows only the current subfile's headings. Title: >
      Headings (subfile) [<C-g>: full doc]
<
  Global mode ~
    Shows the full document TOC from the root file, with the cursor
    pre-positioned on the first heading from your subfile. Title: >
      Headings (full doc) [<C-g>: subfile]
<
Press `subfile_toggle_key` (default `<C-g>`) inside the picker to switch
between modes.

Manual root override: >

  cached_headings = {
    root_file          = "/home/user/thesis/main.tex",
    subfile_toggle_key = "<C-g>",
  }
<

8. COPY HEADING                          *telescope-cached-headings-copy*
                                              *cached-headings-copy*

Press `copy_label_key` (default `<C-y>`) inside the picker to copy the
selected heading's title to the system clipboard (`+` register) without
opening the file. The copied text is the clean extracted title — e.g.
`Introduction` from `\section{Introduction}` or `## Introduction`.

copy_transform ~

An optional hook that transforms the title before it is placed in the
clipboard. Accepts two forms:

Table — map title prefixes to Lua format strings (`%s` is the full title): >

  copy_transform = {
    ["Appendix"] = "appendix~\\ref{%s}",
  },
<

Function — for any transformation logic: >

  copy_transform = function(title)
    return "[[" .. title .. "]]"  -- wiki-link style
  end,
<

When `copy_transform` is `nil` (the default) the raw extracted title is
copied.

9. CONFIGURATION                          *telescope-cached-headings-config*

All options are passed in the `extensions.cached_headings` table during
`telescope.setup()`.

cache_strategy ~
    Type:    string
    Default: `"global"`

    Controls where cache files are stored.

    `"global"` (recommended)
      Stores all caches in Neovim's standard data directory:
        stdpath("data")/cached_headings/<hash>.headings
      Keeps your project directories clean.

    `"local"`
      Creates a hidden file next to the source file:
        /path/to/dir/.filename.ext.headings
      Useful if you want to inspect or share the cache. Remember to add
      `*.headings` to your `.gitignore`.

allowed_filetypes ~
    Type:    string[]
    Default: `{ "tex", "markdown", "org" }`

    List of Neovim filetype strings for which the plugin is active.
    The picker and update commands do nothing for files not in this list.

auto_update ~
    Type:    boolean
    Default: `false`

    When `true`, the cache is regenerated every time you save a supported
    file (`BufWritePost`).
    WARNING: On very large files this may cause a brief pause on save.

enable_smart_jump ~
    Type:    boolean
    Default: `true`

    See |cached_headings-smart-jump| for a full description.
    Set to `false` to always jump straight to the cached line number.

smart_jump_window ~
    Type:    integer
    Default: `200`

    The number of lines to search on each side of the cached position when
    a heading is not found at its expected location.
    Only relevant when `enable_smart_jump = true`.

include_starred ~
    Type:    boolean
    Default: `false`

    LaTeX only. When `true`, starred sectioning commands such as
    `\section*`, `\subsection*`, etc. are included in the picker and cache.
    Starred entries are shown with a trailing ` *` in the picker display.

scan_includes ~
    Type:    boolean
    Default: `false`

    LaTeX only. When `true`, `\input`, `\include`, and `\subfile` directives
    are followed and headings from all referenced files are shown in a single
    unified picker in document order.
    See |telescope-cached-headings-multifile|.

recursive_limit ~
    Type:    integer
    Default: `5`

    Maximum include nesting depth when `scan_includes = true`. Guards against
    circular includes.

ignore_include_pattern ~
    Type:    string
    Default: `""`

    A Lua pattern string. Include paths that match this pattern are skipped
    during multi-file scanning. Empty string disables filtering.

root_file ~
    Type:    string
    Default: `""`

    Absolute path to the root `.tex` file. Used as a manual fallback when
    the `\documentclass[...]{subfiles}` heuristic fails or is non-trivial.
    See |telescope-cached-headings-subfile|.

subfile_toggle_key ~
    Type:    string
    Default: `"<C-g>"`

    Key (in both insert and normal mode) to toggle between local (subfile)
    and global (full document) view inside the picker. Only active when the
    plugin has detected a root file that differs from the file you are
    editing.

copy_label_key ~
    Type:    string
    Default: `"<C-y>"`

    Key (in both insert and normal mode) to copy the selected heading's
    extracted title to the system clipboard (`+` register) without
    navigating to the file.

copy_transform ~
    Type:    table | function | nil
    Default: `nil`

    Optional transformation applied to the heading title before it is placed
    in the clipboard.

    When a table, keys are title-prefix strings and values are Lua format
    strings where `%s` is replaced by the full title. The first matching
    prefix wins; unmatched titles are copied unchanged.

    When a function it receives the title string and must return the
    transformed string.

    When `nil` the raw extracted title is copied.

    See |telescope-cached-headings-copy| for full examples.

==============================================================================
10. COMMANDS                             *telescope-cached-headings-commands*

:Telescope cached_headings                    *:Telescope-cached_headings*

    Open the Telescope heading picker for the current buffer.
    Generates the cache on first use for a given file.

:CachedHeadingsUpdate                            *:CachedHeadingsUpdate*

    Force-regenerate the cache for the current file by re-scanning it from
    disk. Use this after making significant structural changes to a file.
    Prints the number of headings found when complete.

:CachedHeadingsWipeAll                          *:CachedHeadingsWipeAll*

    Delete every cache file written by this plugin and print how many were
    removed.  Useful when you want a guaranteed clean slate — for example
    after upgrading the plugin or if you suspect stale caches from a previous
    version.

    The next time you open the picker for any file the cache is regenerated
    automatically from scratch.

    Note: only supported with `cache_strategy = "global"`.  With `"local"`
    the cache files are scattered next to your source files; delete them
    manually (they match the glob `*.headings`).

==============================================================================
11. KEYBINDINGS                         *telescope-cached-headings-keybindings*

Suggested mappings to add to your Neovim config: >

  -- Open the heading picker
  vim.keymap.set("n", "<leader>fh",
    "<cmd>Telescope cached_headings<cr>",
    { desc = "Find headings (cached)" })

  -- Wipe all caches (re-parsed automatically on next picker open)
  vim.keymap.set("n", "<leader>fH",
    "<cmd>CachedHeadingsWipeAll<cr>",
    { desc = "Wipe all heading caches" })
<
